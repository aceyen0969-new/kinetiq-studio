# KINETIQ® Creative Studio

A fictional creative-agency concept website for a web development portfolio. Built with React, Vite, Framer Motion, Lucide React, and custom responsive CSS.

## Run locally on Windows

Open this folder in VS Code, then run these commands in the terminal:

```powershell
npm.cmd install
npm.cmd run dev
```

Open the local URL Vite prints in the terminal, usually `http://localhost:5173`.

## Build for production

```powershell
npm.cmd run build
npm.cmd run preview
```

## Deploy

Import the project into a GitHub repository, then import that repository into Vercel. Use the Vite preset, `npm run build` as the build command, and `dist` as the output directory.

## Before publishing

KINETIQ is a fictional portfolio concept. The sample project names and `hello@kinetiq.studio` contact address are placeholders. Replace them with accurate contact details before presenting the site as a live business. Check name and trademark availability before using KINETIQ commercially.
